Detención de emergencia de cabinas

Modelo + referencia analítica

Pregunta del caso: ¿cómo varían el tiempo y la distancia de detención frente a cambios de velocidad, tiempo de reacción y frenado, y si la distancia disponible alcanza?

dx/dt = v    dv/dt = −a    (fase de frenado, a constante)
t_f = v₀/a    t_total = t_r + t_f    d_r = v₀t_r    d_f = v₀²/(2a)    d_total = d_r + d_f
x_final = x₀ + d_total    margen = d_disponible − d_total
Introduce los parámetros y ejecuta el escenario.

Subexperimento MAL CONDICIONADO — desaceleración variable

Se usa dv/dt = −(a₀ − k v), con a₀,k>0 y v₀<a₀/k. La solución analítica es:

v(t)=a₀/k + (v₀−a₀/k)e^{kt};   t_f=(1/k)ln[(a₀/k)/(a₀/k−v₀)];   d_f=(a₀/k)t_f − v₀/k

Cuando v₀ → a₀/k, el denominador a₀−kv₀ → 0 y ∂t_f/∂v₀ = 1/(a₀−kv₀) crece sin límite. Esto demuestra que el tiempo de detención se vuelve extremadamente sensible a v₀ cuando v₀ se aproxima a a₀/k.

Ejecuta el subexperimento para ver la sensibilidad cerca de la singularidad.

MÓDULO 2

Deterioro mecánico y mantenimiento

Tres escenarios ejecutables

Pregunta del caso: ¿cuándo alcanzaría un indicador hipotético de deterioro un umbral de inspección y cómo cambia la estimación con la incertidumbre de los parámetros y con un mantenimiento retrasado?

D(t) = D₀ + αt + βt²    D(t) − D_umbral = 0
t* = [−α + √(α² − 4β(D₀ − D_umbral))]/(2β)    (β>0; se elige la raíz positiva físicamente admisible)
D′(t*) = α + 2βt*    1/|D′(t*)| = condición absoluta de la raíz    S_p = (p/t*)·(∂t*/∂p)
Parámetros del escenario NORMAL
Selecciona un escenario y ejecútalo.
Presiona «Analizar sensibilidad» para estimar derivadas, elasticidades y condición de la raíz.

Mantenimiento retrasado (modelo analítico)

Se evalúa un mantenimiento en el instante t_m que reduce el indicador en r unidades. Después del mantenimiento se conservan α y β y se vuelve a resolver el umbral.

D_antes = D₀ + αt_m + βt_m²    D_después = D_antes − r    t_total = t_m + s, donde D_después + αs + βs² = D_umbral
Introduce el instante y la reducción para comparar con el caso sin mantenimiento.

Variables y unidades

VariableUnidadSignificado

D₀índiceValor inicial del indicador.

Hipótesis y alcance

  • Modelo cuadrático con α≥0 y β≥0; los coeficientes son constantes en el intervalo simulado.
  • El indicador es adimensional y el umbral es una política de inspección, no una falla instantánea.
  • La raíz físicamente admisible es la menor raíz no negativa; si no existe, el modelo no predice el cruce.
  • El mantenimiento se modela como una reducción instantánea r en t_m, conservando la tendencia posterior; no se modelan reparaciones parciales ni cambios de α, β.
  • Alcance: datos sintéticos; el resultado no es una predicción de falla real.

Fuente de parámetros: valores supuestos con fines didácticos; no provienen de registros de Mi Teleférico.

MÓDULO 3

Oscilaciones por viento

Modelo + referencia analítica

Pregunta del caso: ¿cómo se modifica la oscilación ante cambios de fuerza externa, amortiguamiento y parámetros del modelo?

x′ = v    v′ = [F(t) − cv − kx]/m    F(t)=F₀ sen(ωt)
ω₀=√(k/m)    ζ=c/(2√(km))    ω_d=ω₀√(1−ζ²) (ζ<1)
x_libre(t)=e^{−ζω₀t}[C₁cos(ω_dt)+C₂sen(ω_dt)]    C₁=x₀    C₂=(v₀+ζω₀x₀)/ω_d

Los controles son de solo lectura en S1 porque la simulación RK2/RK4 y la integración corresponden a S2. La referencia analítica y la sensibilidad de la amplitud ya se calculan aquí.

PARTE TRANSVERSAL · SEMANA 1

Teoría de errores

Error absoluto

E_a = |V_r − V_a|

Error relativo

E_r = |V_r − V_a| / |V_r|,   V_r ≠ 0

Error porcentual

E_p = 100·E_r

Residual lineal

r = b − Ax    ||r||∞

El error relativo y porcentual no se calculan cuando la referencia es cero. La sensibilidad se estudia perturbando parámetros o datos y comparando la variación de resultados. En esta entrega se aplica en los cuatro módulos: M1 (distancias y tiempos), M2 (raíz y mantenimiento), M3 (amplitud y resonancia) y M4 (nodos y Vandermonde).

Dónde se aplica cada métrica

Error relativoSistemas lineales, elasticidades de M2, sensibilidad de M1/M3.
Error porcentualTabla de sistemas lineales y calculadora transversal.

Sistemas de ecuaciones lineales

Se comparan Jacobi, Gauss-Seidel, LU y gradiente conjugado sobre sistemas SPD de tamaño 4×4 con solución de referencia conocida. La matriz A es bien condicionada y estrictamente diagonal dominante; la matriz H de Hilbert es SPD pero mal condicionada, lo que permite distinguir error, residual y condicionamiento.

En M2, estos solvers se usarán para calibrar coeficientes de un modelo de ajuste. En S1 se prueba el núcleo numérico con sistemas sintéticos y solución exacta conocida.

Condiciones de convergencia

  • A: simétrica, definida positiva y estrictamente diagonal dominante; Jacobi y Gauss-Seidel convergen y el gradiente conjugado es aplicable.
  • H: simétrica y definida positiva, pero no es diagonalmente dominante; Jacobi puede divergir, Gauss-Seidel converge lentamente y el gradiente conjugado requiere más cuidado por el mal condicionamiento.
  • El gradiente conjugado estándar se usa solo con matrices SPD; el código verifica que la dirección de búsqueda no genere un denominador no positivo.
  • LU se implementa sin pivoteo: es válido para estas matrices con pivotes no nulos, pero no es un solver robusto para matrices generales.
