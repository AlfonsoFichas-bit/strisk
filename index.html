Semana 1 · Prototipo

MÓDULO 1

Detención de emergencia de cabinas

Modelo planteado

Se estudia el tiempo y la distancia necesarios para detener una cabina ante un frenado de emergencia, usando desaceleración constante como referencia analítica.

dx/dt = v    dv/dt = −a
v(t) = v₀ − at    x(t) = x₀ + v₀t − (a/2)t²
t_det = v₀/a    d = v₀²/(2a)
Introduce los parámetros y calcula.

Relación entre métodos y el caso

  • EDO: Runge-Kutta de segundo y cuarto orden (RK2 y RK4).
  • Integración: trapecio compuesto, Simpson 1/3 compuesto y Romberg.
  • Raíces: bisección, Newton-Raphson y secante para v(t) = 0, cuando corresponda.

Semana 1: modelo, variables, unidades, hipótesis y escenarios. La implementación de EDO, integración y raíces corresponde al avance posterior.

Escenarios definidos

EscenarioParámetros propuestosPropósito
NORMALv₀ = 10 m/s; a = 1.5 m/s²Condición nominal.
ESTRÉSv₀ = 14 m/s; a = 1.0 m/s²Mayor velocidad y menor desaceleración.
MAL CONDICIONADOPrueba numérica con raíz sensible o derivada pequeña, separada del riesgo físico.Estudiar sensibilidad de la solución.

MÓDULO 2

Deterioro mecánico y mantenimiento

Tres escenarios ejecutables

Se estima cuándo un indicador hipotético de deterioro alcanza un umbral de inspección.

D(t) = D₀ + αt + βt²
D(t) − D_umbral = 0
Selecciona un escenario.

Relación entre métodos y el caso

  • Raíces: bisección, Newton-Raphson y secante para D(t) − D_umbral = 0.
  • Sistemas lineales: Jacobi, Gauss-Seidel, LU y gradiente conjugado para estimar coeficientes de calibración, si se construye ese ajuste.
  • Integración de la tasa de deterioro: opcional.

Los parámetros son sintéticos y sirven únicamente para la práctica académica.

Definición de escenarios de los otros módulos

Módulo 1: NORMAL (v₀=10, a=1.5); ESTRÉS (v₀=14, a=1.0); MAL CONDICIONADO: experimento numérico de raíz con alta sensibilidad.

Módulo 3: NORMAL (m=1000, c=500, k=20000, F(t)=1000sen(2t)); ESTRÉS (mayor fuerza externa o menor amortiguamiento); MAL CONDICIONADO: parámetros perturbados que demuestren sensibilidad numérica.

Módulo 4: NORMAL (y=sen(t), nodos regulares); ESTRÉS (datos con ruido); MAL CONDICIONADO (nodos desfavorables o muy próximos que amplifiquen perturbaciones).

MÓDULO 3

Oscilaciones por viento

Modelo planteado

Se estudia el desplazamiento de una cabina idealizada sometida a una fuerza externa y a un amortiguamiento.

x′ = v    v′ = [F(t) − cv − kx]/m

Relación entre métodos y el caso

  • EDO: RK2 y RK4.
  • Integración de |x(t)| o x(t)²: trapecio, Simpson y Romberg.
  • Sistemas lineales auxiliares para calibración, si corresponde.

Escenarios definidos

EscenarioDefinición
NORMALm=1000 kg, c=500 N·s/m, k=20000 N/m, F(t)=1000 sen(2t) N.
ESTRÉSMayor fuerza externa o menor amortiguamiento, manteniendo unidades.
MAL CONDICIONADOSubexperimento numérico con parámetros cuya perturbación cambie significativamente el resultado.

Los valores se declaran como supuestos sintéticos; no representan especificaciones reales de una cabina.

MÓDULO 4

Reconstrucción de señales de sensores

Modelo planteado

Se reconstruyen datos faltantes a partir de una función sintética conocida y se mide la diferencia entre los valores reconstruidos y los valores de referencia ocultados.

y(t) = sen(t)

Intervalo: [0, 2]. Nodos: 0; 0.5; 1; 1.5; 2.

Puntos de prueba ocultados: 0.25; 0.75; 1.25; 1.75.

tReferencia sen(t)Uso

Relación entre métodos y el caso

  • Interpolación de Lagrange.
  • Newton por diferencias divididas.
  • Splines cúbicos.
  • Sistemas lineales auxiliares para construir splines, cuando corresponda.

Escenarios definidos

  • NORMAL: nodos regulares y datos sintéticos sin ruido.
  • ESTRÉS: datos con perturbaciones o ruido mayor.
  • MAL CONDICIONADO: nodos desfavorables o cercanos que generen alta sensibilidad de la interpolación.

Los métodos de interpolación se implementarán en la etapa correspondiente del cronograma.

PARTE TRANSVERSAL · SEMANA 1

Teoría de errores

Error absoluto

Ea = |Vr − Va|

Error relativo

Er = |Vr − Va| / |Vr|

Error porcentual

Ep = Er × 100

Residual lineal

r = b − Ax

El error relativo y porcentual no se calculan cuando la referencia es cero. Se debe evitar la división por cero y explicar la métrica alternativa utilizada. La sensibilidad se estudia perturbando parámetros o datos y comparando la variación de resultados.

Referencia y método directo LU

La solución de referencia es x* = (1, 2, 3, 4). LU realiza una factorización y resolución directa; Jacobi, Gauss-Seidel y gradiente conjugado son iterativos.

El gradiente conjugado estándar requiere matriz simétrica definida positiva. No se debe utilizar con matrices que no cumplan esa condición.
